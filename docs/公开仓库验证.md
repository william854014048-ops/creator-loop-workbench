个人作品、加密密钥、运行日志、浏览器临时资料、本机发行包、验收材料和内部开发计划已排除。初始配置中的模型名称与密钥留空，由使用者在页面中配置。

本次整理增加 README 下载与启动说明、目录说明、测试工具安装方法、界面预览和上传排除规则。程序版本沿用 `VERSION` 中的 `0.2.0`。
